Scope of this report: VERITAS automates evidence generation for the NIST AI RMF MEASURE function and produces citations into MAP and MANAGE. It does not, and cannot, produce evidence for the GOVERN function (organizational accountability, training, documented risk tolerance) — that remains the deploying organization's responsibility. A violation-tier finding citing MANAGE 1.3/1.4 documents that a response is owed; it does not itself constitute that response. Anomaly findings are informational-only by design: no externally defensible severity cutoff currently exists for the anomaly detector, so anomaly findings never escalate to MANAGE (see project documentation for the reasoning).
